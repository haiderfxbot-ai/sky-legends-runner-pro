# Assets Directory

This directory contains all game assets.

## Subdirectories

- `icons/` - UI icons and buttons
- `backgrounds/` - Background images
- `characters/` - Player character sprites
- `enemies/` - Enemy sprites
- `effects/` - Visual effects
- `particles/` - Particle textures (generated procedurally)
- `sounds/` - Sound effects
- `music/` - Background music
- `fonts/` - Custom fonts

## Note

All textures are generated procedurally in the BootScene for optimal performance. You can replace them with custom assets by loading them in the LoadingScene.
